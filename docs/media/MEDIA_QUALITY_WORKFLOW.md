# CodeRoute Guinée — Phase 4 quality gate et validation média

Cette phase installe le workflow humain et le back-office de la médiathèque.

Règle de compatibilité : les questions historiques qui n'ont pas encore de `QuestionMedia(primary)` restent compatibles jusqu'à la Phase 7. Dès qu'une question utilise un média principal normalisé, son approbation officielle doit être bloquée tant que ce média ne satisfait pas le quality gate et la validation réglementaire.
